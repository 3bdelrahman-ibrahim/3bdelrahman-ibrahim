## 👋 About Me

I'm a software engineer focused on building cross-platform mobile applications with **Flutter and Dart**, combining thoughtful UI/UX design with maintainable code and reliable backend integrations.

I enjoy turning ideas into practical digital products, from designing user interfaces to integrating APIs, testing features, and preparing applications for release.

- 📱 Developing mobile applications for Android and iOS.
- 🎨 Creating intuitive interfaces and polished user experiences.
- 🔗 Integrating REST APIs, authentication, databases, and cloud services.
- 🌍 Building Arabic and English experiences with RTL support.
- ⚡ Interested in mobile performance, automation, and AI-powered features.
- 🚀 Focused on shipping useful products and improving them through iteration.

🎓 **Education:** Bachelor's degree in Mechatronics Engineering, Canadian International College (CIC), 2019–2024.

📍 Cairo, Egypt · Open to software engineering opportunities across Egypt and the Gulf.
